# Just Studio — сайт

## Как открыть
Откройте `index.html` в браузере. Для публикации загрузите все файлы и папку `assets` на ваш хостинг.

## Логотип
Положите файл логотипа в `assets` и назовите его `logo.png`. Логотип автоматически обрезается в круг через CSS. Если у вас JPG или WebP, поменяйте имя файла в `index.html` в двух местах.

## Как добавлять проекты
Откройте `projects.js`. В массиве `projects` уже есть JP FPS Displayer. Скопируйте объект проекта, вставьте после него через запятую и измените поля:
- `title` — название;
- `type` — например `Minecraft MOD`, `BOT`, `PLUGIN`, `GAME`;
- `status` — статус;
- `description` — описание;
- `image` — путь к картинке, например `assets/bot.png`, или прямая ссылка на изображение;
- `links` — кнопки проекта. Для бота можно указать `https://t.me/имя_бота`.

Пример:
```js
{
  title: "My Telegram Bot",
  type: "BOT",
  status: "Работает",
  description: "Бот для ...",
  image: "assets/my-bot.png",
  links: [
    { label: "Открыть бота", url: "https://t.me/my_bot" },
    { label: "Подробнее", url: "https://example.com" }
  ]
}
```
Не забудьте поставить запятую между объектами массива, но не после последнего объекта.
